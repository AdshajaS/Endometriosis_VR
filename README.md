# EndoVR: VR Patient Education for Endometriosis 


A virtual reality tool that aims to help newly diagnosed endometriosis patients understand their condition, the different treatment options available to them and symptom management, through interactive 3D animations. 


## What it does
- Explains what endometriosis is using an anatomical 3D model
- Walks through the different treatments: laparoscopy, hormone therapy, pain killers and hysterectomy
- The tool is navigated with handheld controllers or hand tracking on Meta Quest

## Built with:
**Blender**: 3D animation
**Unity**: VR app and interaction
**ITK-SNAP**: Anatomical segmentaion of the uterus 
**Sketch-Fab**: Used pre-existing models as a base
**Meta Quest**: VR headset



## Notes
Built as a 3D Clinical Anatomy Project at King's College London University.
